# SocialPilot Android Share

Native Android share target for SocialPilot AI. It receives images/videos from the Android Sharesheet and uploads them directly to SocialPilot.

## Build
Use Android Studio or GitHub Actions. Minimum Android SDK 26; target/compile SDK 36.

## Pairing
Install the app, open SocialPilot's mobile share pairing page, pair the device, then use the Android share sheet from Gallery/Photos.
